# 大祥老师的终末地助手 v2.0.0 · 明日方舟：终末地

版本 **2.0**　发布者 **Luyoo**

仓库：https://github.com/hdwy001/skill-axis-endfield

一个**只读**的悬浮提示工具：事先把技能释放顺序排好，游戏里按对应按键，悬浮窗自动跳到下一个技能。

不注入游戏、不改内存、不模拟按键，只被动监听键盘/手柄。

---

## 特性

- **编队制**：一个编队 = N 条充能轴 + 1 条爆发轴，无限循环；每个编队有独立的 4 人队伍
- **队伍可拖拽换位**：按住头像左右拖（先按住 0.2 秒防误触），原位置让出空缝、其余整体挪开，松手落位（插入式，不是对调）；同一位干员在队伍里只会存在一次（选人窗里重复选中 = 两个位置互换）
- **单轴循环**：某条充能轴可单独设「走 N 遍」再往下
- **多段战技**：祀/明河/噗切娜/梨诺 的战技、诀的战技·连携·终结 都有两段，技能栏按**名字**列卡（如「战技·智诀 / 战技·意诀」）
- **分支路线**：主线放分支点，按预设键走不同路线轴，可选「汇合回主线 / 各走各的」
- **长条悬浮窗**：一条横向流水线，从左到右即释放顺序；当前用琥珀描边框标出，按过的变暗
- **宽度自适应**：技能少就短，多就长；可拖边框**等比缩放**
- **透明度可调**：只影响底色，文字始终清晰（逐像素 alpha，非抠图）
- **按键规则照游戏**：
  - 键盘：战技=短按 `1~4`（按队伍位）、连携=`E`、终结=长按同数字
  - 手柄：连携=`RB`、战技=`LB` + `X/Y/A/B`；终结技两种风格可选（长按面键 / `LB`+`RB`+面键），照游戏内设置选同一种
- **键位可自定义**：键盘的队伍 1~4、连携技、四个快捷键，以及手柄的连携/修饰/面键，都在「设置 → 键盘按键 / 手柄按键」里点按钮换绑；撞键会提示，单卡片可一键恢复默认
- **自动保存**：改动 0.8 秒后落盘，切换编队/退出时立即保存
- **自动提权**：游戏常以管理员运行，程序会请求管理员权限（否则钩子收不到按键）

## 运行

需要 Python 3.10+ 和 Pillow。

```bash
pip install -r requirements.txt
python main.py
```

首次运行会自动下载技能图标与干员立绘：

```bash
python tools/fetch_icons.py
python tools/fetch_portraits.py
```

## 自测

```bash
python main.py --selftest     # 225 项逻辑自测
python main.py --smoke        # 构界面后自动关闭
```

## 打包成 exe

需要 PyInstaller（`pip install pyinstaller`）：

```bash
python tools/build_package.py
```

产物在 `dist/大祥老师的终末地助手/`，与 `data/` 同级即可免安装运行。

## 使用提示

- 游戏必须**窗口化**或**无边框窗口**，独占全屏会盖住悬浮窗
- 请**以管理员身份运行**，否则游戏窗口获得焦点时收不到按键
- 快捷键：`F7` 开始/暂停　`F8` 重置　`F9` 显示/隐藏　`F10` 点击穿透
